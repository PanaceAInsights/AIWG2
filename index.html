1Source data capture (Vectra WB360)

3D total body photography captured at each site. Output formats: CR2 (raw camera files, identifiable), JSON (de-identified lesion metadata), TOM (3D mesh files). Stored in site-local Vectra clinical database.

2Cleansed export from Vectra DB

VectraDBTool + exporter runs locally at each site. Removes patient name, DOB, ID. Retains External ID for REDCap linkage. Output: per-patient .db file plus CR2, JSON, TOM folders.

runs site-local

3aNaevus burden processing (Script 1)

Reads JSON files. Filters by confidence (≥80%) and major axis (≥2 mm). Outputs CSV of naevi per body site per participant. Broad location labels (e.g. "Left Leg" without upper/lower) affect ~7% of participants.

processing time ~minutes

3bPhotodamage processing (Script 2)

CR2 → JPEG conversion → tile into 9×5 grid → HSV/YCbCr skin filter → AI model inference per tile. Aggregation methodology to per-body-site and per-individual under discussion.

heavier processing · hours

3cFreckling processing

7 body-location CR2 views → PNG conversion → region-specific extraction (arms rotated 90°, back ROI until skin >75%, face cheek crop via MediaPipe). Algorithm currently being externally validated.

~20h export per cohort

4Analysis-ready outputs → downstream projects

Phenotype-specific CSVs feed into the eight downstream projects. Most analyses currently waiting on dataset completion across sites and pathology review of outcomes.

Enablers and blockers

Forces currently supporting progress, and items awaiting resolution.

Enablers supporting progress

  • ISIC tile extraction tool now functional. Filter paper progressing on Alfred data.
  • Updated Canfield CR2 conversion utility resolves earlier image format incompatibility.
  • Script 1 distributed across sites, with first extraction results from PA presented.
  • Existing ethics framework covers the Dexi 3.0 evaluation without requiring new submission.
  • Two risk-model workstreams formalised as distinct projects (deep learning vs interpretable incremental).
  • MIA access established for NSW work, enabling baseline risk data extraction and local script execution.
  • Operations coordination role centralised with Sam Polkinghorne-Katz across workstreams.

Blockers awaiting resolution

  • Photodamage AI model distribution. Model being prepared for sharing with the wider extraction team for Script 2 integration.
  • Photodamage aggregation methodology. Per-tile outputs need translation to per-body-site and per-individual scores for analysis.
  • Pathology review of ~100 outstanding melanoma slides is a prerequisite for outcome-based analyses across multiple projects.
  • NSW cross-site data sharing pathway unresolved. No national repository yet. Working assumption: distributed extraction.
  • Freckling external validation awaiting Alfred image transfer to UQ and annotator capacity.
  • Filter paper labelling approach. Distinction between "lesions for dermoscopy" vs "lesions for biopsy" being defined.
  • Per-site sequential extraction. Image data must be cleaned at each site before scripts can run.
